# CV-Match-Pro

Plateforme intelligente de tri et de matching de CVs.

## Description
Ce projet permet de trier automatiquement des CVs et de les comparer
à une offre d'emploi grâce à un modèle de Machine Learning (ML.NET).

## Technologies utilisées
- C# / .NET
- ML.NET
- Visual Studio

## Installation
1. Cloner le dépôt :
   git clone https://github.com/Mouadsekkoumi/CV-Match-Pro.git
2. Ouvrir le fichier `CVMatchPro.sln` avec Visual Studio.
3. Restaurer les packages NuGet puis lancer le projet (F5).
